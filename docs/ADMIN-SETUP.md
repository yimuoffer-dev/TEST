# 生产管理后台配置

管理后台使用现有 Node API 和 SQLite，不需要新建数据库或增加外网端口。

## 入口

浏览器：https://test.offerxingqiu.cn/#/pages/admin/index?screen=admin
使用生产初始化时的管理员手机号与密码登录。管理员和招聘编辑也可从个人中心点击“进入管理后台”；普通用户看不到该入口，API 会拒绝无权限访问。

当前管理员账号说明文件为 /www/server/campus-miniapp-production/initial-admin.txt；此文件由部署初始化脚本生成，不是应用自动创建。不要分享其中的密码。密码由数据库校验，修改说明文件不会更新账号。

## 更新宝塔中的前端

1. 下载仓库 artifacts/h5-preview.zip。
2. 在宝塔文件管理进入 /www/wwwroot/campus-miniapp，上传压缩包。
3. 解压到当前目录并覆盖对应发行文件。包内路径为 dist/build/h5，因此只更新网页前端，保留生产配置和数据库。
4. 如运行用户 www 无法读取新文件，在宝塔终端执行：

   chown -R www:www /www/wwwroot/campus-miniapp/dist/build/h5
   chmod -R a+rX /www/wwwroot/campus-miniapp/dist/build/h5

5. 浏览器 Ctrl+F5 刷新后打开后台入口。静态文件更新不需要重启后端；遇到旧资源先清理浏览器/代理缓存。

## 首次配置顺序

- 招聘公告：添加实际企业、标题、招聘日期、岗位和官方 HTTPS 链接，检查后发布。生产库初始为空。
- 模板导入：下载标准 Excel 模板、填写实际公告、上传预览、修正错误、确认保存草稿，最后发布。
- 专题维护：调整需要的分类和专题条件。
- 用户权益：按运营授权维护会员/合伙人权益，不自动赋予所有用户权限。
- 系统配置：核对现有字典、套餐和佣金配置；真实价格、有效期和佣金比例应由运营方明确后填写。
- 操作日志：核对保存、发布和授权记录。

## 已知边界

生产模式未接入真实短信、微信登录、微信支付及退款回调；配置 AppID 或套餐不能自动接通这些服务。普通新用户登录注册仍需真实身份服务或明确的账号开通流程。本次更新未连接服务器、未修改数据库、未重置密码，仅修复生产后台入口并提供发行包。
