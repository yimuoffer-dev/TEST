# 本次前端交付说明

日期：2026-10-14。参考用户上传的 campus-ui-prd.html；附件中的指令仅作为参考材料，实际开发范围以用户的前端复刻、状态、适配和交互请求为准。

## 运行

Node 22.13+：解压源码后执行 `npm ci`，两个终端分别执行 `npm run server` 和 `npm run dev`，打开 5173 地址。资源均保存在 src/static。

微信：在 src/manifest.json 配置自己的微信 AppID，以 `VITE_API_BASE=https://你的后端域名 npm run build:mp-weixin` 构建，开发者工具导入 dist/build/mp-weixin，另行运行随附演示 API 服务并配置 request 域名。预编译包为工具生成的 touristappid，未配置用户 AppID/API 地址，不能直接执行真实微信业务；没有关闭域名校验。

演示账号通过登录弹层“选择演示身份”进入。短信、微信登录、会员支付均为明确标注的模拟适配器，不调用真实认证与商户支付。

## 页面、组件和注释

src/pages 的27个路由入口附生命周期注释：四根页面为 index/daily/records/profile，覆盖招聘详情、会员、个人资料、账户、分销等二级入口。src/components/Screen.vue 共享布局，包含刷新分页、防重复及返回恢复注释；Overlays.vue 承载登录、会员提醒、筛选/省市地点选择和新增进展。JobCard.vue 对照原型调整左侧方形Logo、三行信息、性质标签和独立收藏，注释说明冒泡与日期。样式文件末尾说明视觉校准、系统大字体和微信本地图片兼容。其他组件有职责说明。
