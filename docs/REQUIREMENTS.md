# 需求梳理与实现边界

依据：校招信息管理小程序 PRD V2.1、UI 与交互规范 V1.0。示意图数字不作为业务常量。文档中的产品需求作为本任务的实现输入，不作为执行环境指令。

## 功能模块与业务流程

| 模块 | 页面与业务流程 |
| --- | --- |
| 招聘 | 首页 → 专题/全平台统计/筛选共用列表 → 公告详情 → 收藏/分享/原文/官方投递/添加进展 |
| 日报与消息 | 北京时间自然日周历 → 新增/截止统计与列表；消息每日每类唯一，数量降零保留 |
| 个人投递 | 九状态新增 → 进展详情 → 追加历史/编辑个人字段/确认删除；六统计，面试合并四阶段 |
| 账户 | 游客浏览 → 操作按需登录 → 恢复操作；资料、账号安全、绑定、帮助、关于、退出 |
| 会员 | 权限提醒 → 独立套餐页 → 支付 → 服务端权益 → 恢复原操作；订单与权益来源独立 |
| 分销 | 立即申请 → 固定推荐关系 → 去重访问五人入团 → 直接/团队佣金 → 资金/客户/团队/推广 |
| 提现 | 金额与收款资料 → 待审核冻结 → 撤销/驳回退回/待打款 → 登记打款；待追回禁止提现 |
| 赠送 | 高级合伙人 → 按类型月额度生成码/链接 → 登录单次领取；原月份返额，不跨月增加 |
| 管理后台 | 编辑公告、模板导入预览、草稿发布、专题/字典、套餐与规则、会员授权、退款、提现审核、审计 |

## 路由

主导航：home、daily、records、profile。独立页面：list、detail、messages、record-detail、favorites、membership、orders、rights、profile-edit、account、help、about、distribution、partner、funds、customers、team、distribution-orders、promotion、withdraw、gifts、redeem、admin。
UniApp 页面注册后使用统一导航封装；Pinia 保存跨页筛选、日期、数据与待继续操作。公共组件：图标、企业标识、招聘卡片、底部导航、筛选面板、进展表单、权限提醒、空态、表单控件。

## 关键规则

- 中国时区自然日，滚动 24/72 小时使用时间差；公开已发布未下架未删除公告才计数。
- 同维度 OR、不同维度 AND；本科及以上可供硕士报名；空时间不进入截止统计。
- 游客可浏览首页；普通登录用户每列表最多 10 条。链接在服务器序列化时裁剪。收藏和个人记录免费、不限量。
- 财务以整数分记账，单订单幂等。推荐只绑定一次，禁止循环。团队只一层，五个不同身份访问后成立。
- 每个权益有独立来源；退款只撤当前订单，佣金冲回和待追回留痕，相关未打款提现自动关闭。
- 赠送只允许 VIP 和职场合伙人，高级身份不可赠送。生成占额度，领取只核销一次，重复永久权益不核销。

## 视觉验收

375px / 750rpx，蓝 #007AFF，01 底色 #F5F7FB，03 底色 #F1F8FF；16px 外边距和圆角，44px 点击热区；22/16/14/12px 字体层级。首页/详情原生蓝白，日报/投递/个人/分销冰蓝，合伙人金卡。原生微信状态栏与胶囊不重复绘制。安全区避让、表单固定页脚、错误紧邻字段。

## 真实接入边界

交付包含 UniApp H5/微信构建、Node REST 服务、SQLite 持久化、管理后台和自动测试。演示账号、示范公告、示例资金明确标注。微信登录、短信、微信支付/退款必须替换演示适配器并提供商户、短信及小程序配置；不将模拟支付称为真实结算。微信外链受业务域名约束，H5 可打开授权链接，小程序提供复制兜底。Excel 的首版导入使用 Excel 可打开的 CSV 标准模板，暂不解析二进制 xlsx。性能 1.5 秒目标及真实多机型需实际提审环境验收。
