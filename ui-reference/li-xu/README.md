# 礼序 · 八屏 HTML 复刻

打开 `index.html` 即可使用，无构建步骤、无 CDN 或网络依赖。内嵌 Noto Serif CJK SC 的页面字形子集（附字体许可），其余用户输入字符使用系统宋体回退。

八个界面：`#home` 首页、`#books` 全部礼簿、`#book` 礼簿详情、`#entry` 记一笔、`#people` 人情往来、`#person` 往来详情、`#stats` 统计、`#profile` 我的。

基于参考图的 863px 设计宽度等比适配手机。背景、封面、图标与花卉徽章均直接使用用户提供的 PNG；文字、布局、边框与图表仍为 HTML/CSS。不同素材版本和系统字体会影响与最初参考图的逐像素一致性。

搜索、类型筛选、收送礼切换、关系选择、数字键盘、保存并继续、新建礼簿、导出备份可操作。新增往来存储在当前浏览器 localStorage；新建礼簿为本次会话演示。账户、共享与提醒没有后端接入；统计为固定参考数据，年度按钮只切换展示年份并提示。

验证：在本目录执行 `python3 -m http.server 5180`，在仓库根目录执行 `node ui-reference/li-xu/verify.cjs`。需要仓库已安装的 Playwright 和 `/usr/bin/chromium`。覆盖八屏渲染、窄屏溢出、搜索、筛选、键盘、记账持久化、新建礼簿、原始封面尺寸、PNG 加载、背景引用、单文件内嵌素材及浏览器异常。截图输出 `/tmp/lixu-*.png`，不覆盖原项目交付图。

## 已接入用户素材

`assets/` 保留四个素材压缩包中的 92 个原始尺寸 PNG，包含全部导航状态、操作、礼事、印章、关系、统计及装饰图标。页面导航、操作和花卉徽章已直接调用对应素材。后续提供的 5 张大背景及 6 张礼簿封面已原样保存并接入。首页/统计/婚礼详情/记账使用 background-6，全部礼簿/我的使用 background-8，往来列表/详情使用 background-9；喜庆红 background-7 与庭院 background-10 保留在素材库供替换。六款封面通过类型映射调用，新建礼簿支持升学和追思；原始 PNG 文件保持不变，显示时消除透明留白并按参考图封面槽位缩放。

`礼序-完整复刻.html` 内嵌所有素材，可单文件离线打开；运行 `python3 ui-reference/li-xu/build-standalone.py` 重新打包。

完整单文件约 50 MB，含全部原图；日常开发和加载推荐使用 `index.html` 加 `assets/` 的目录版本，避免一次性解析所有未使用图片。

## 参考图布局校准

`calibration.css` 将静态初始八页统一到 863 × 1822 画布，导航起点为 y=1681。首页搜索 y=358、礼簿卡片 y=569；全部礼簿列表 y=470；礼簿详情头图 y=199；我的卡片 y=208、高 379；记账页键盘 y=1250、保存按钮 y=1674。长列表新增记录后允许自然滚动，不裁掉数据。

校准包含低对比度宣纸背景、独立角落梅枝、参考式转角边框、环形图百分比、状态栏 Wi-Fi、键盘退格、收送礼图标、字体与导航间距。原参考截图未提供可读取文件，因此验证采用参考坐标、浏览器截图审视与布局断言，并非图像差分得出的“零像素误差”；用户后来提供的图标与封面本身也和初始参考图存在版本差异。

运行 `node ui-reference/li-xu/capture.cjs` 可更新 `review/` 下八页 863 × 1822 截图与效果总览。验证脚本另检查 320、375、430、768、863 五种宽度的全部八页、画布高度、底部导航基线、功能交互，以及单文件图像/字体嵌入。开始验证前请先启动本目录的 5180 静态服务器。
