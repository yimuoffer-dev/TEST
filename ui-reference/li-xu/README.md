# 礼序 · 八屏 HTML 复刻

打开 `index.html` 即可使用，无构建步骤、无 CDN 或网络依赖。中文字体优先使用本地宋体/Noto Serif CJK；不同系统字体会影响字形。

八个界面：`#home` 首页、`#books` 全部礼簿、`#book` 礼簿详情、`#entry` 记一笔、`#people` 人情往来、`#person` 往来详情、`#stats` 统计、`#profile` 我的。

基于参考图的 863px 设计宽度等比适配手机。背景、封面、图标与花卉徽章均直接使用用户提供的 PNG；文字、布局、边框与图表仍为 HTML/CSS。不同素材版本和系统字体会影响与最初参考图的逐像素一致性。

搜索、类型筛选、收送礼切换、关系选择、数字键盘、保存并继续、新建礼簿、导出备份可操作。新增往来存储在当前浏览器 localStorage；新建礼簿为本次会话演示。账户、共享与提醒没有后端接入；统计为固定参考数据，年度按钮只切换展示年份并提示。

验证：在本目录执行 `python3 -m http.server 5180`，在仓库根目录执行 `node ui-reference/li-xu/verify.cjs`。需要仓库已安装的 Playwright 和 `/usr/bin/chromium`。覆盖八屏渲染、窄屏溢出、搜索、筛选、键盘、记账持久化、新建礼簿、原始封面尺寸、PNG 加载、背景引用、单文件内嵌素材及浏览器异常。截图输出 `/tmp/lixu-*.png`，不覆盖原项目交付图。

## 已接入用户素材

`assets/` 保留四个素材压缩包中的 92 个原始尺寸 PNG，包含全部导航状态、操作、礼事、印章、关系、统计及装饰图标。页面导航、操作和花卉徽章已直接调用对应素材。后续提供的 5 张大背景及 6 张礼簿封面已原样保存并接入。首页/统计/婚礼详情/记账使用 background-6，全部礼簿/我的使用 background-8，往来列表/详情使用 background-9；喜庆红 background-7 与庭院 background-10 保留在素材库供替换。六款封面通过类型映射调用，新建礼簿支持升学和追思；透明边缘与图像比例保留。

`礼序-完整复刻.html` 内嵌所有素材，可单文件离线打开；运行 `python3 ui-reference/li-xu/build-standalone.py` 重新打包。

完整单文件约 50 MB，含全部原图；日常开发和加载推荐使用 `index.html` 加 `assets/` 的目录版本，避免一次性解析所有未使用图片。
